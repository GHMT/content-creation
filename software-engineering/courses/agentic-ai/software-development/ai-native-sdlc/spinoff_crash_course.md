## 📅 Course Schedule & Outline

### 🌅 Day 1: The Prompt is Code
*   **Video Duration**: 8 minutes.
*   **Topic**: Moving from inline autocomplete (typing helper) to workspace-level agentic editing.
*   **Key Concept**: Workspace indexing, vector databases in IDEs, and how to use context mentions (`@filename`, `@symbol`, `@git`) to feed the AI correct context.
*   **Hands-on Task**: Open your IDE, search your codebase for a specific class using `@symbol`, and ask the AI to refactor it.
*   **CTA**: Preview of Day 2: "How to prevent the AI from making mistakes."

### 🌅 Day 2: The Spec-First Blueprint Pattern
*   **Video Duration**: 10 minutes.
*   **Topic**: The number one mistake developers make is prompting without planning. We introduce the Markdown Blueprint.
*   **Key Concept**: Writing a simple 1-page markdown specification that maps code changes, database updates, and verification tests before writing a line of code.
*   **Hands-on Task**: Write a 5-line specification for adding a new API status endpoint and let the agent implement it.
*   **CTA**: Preview of Day 3: "How to teach your computer to fix its own errors."

### 🌅 Day 3: Build a Self-Healing Dev Loop
*   **Video Duration**: 12 minutes.
*   **Topic**: Connecting the agent to compiler output and test runners.
*   **Key Concept**: TDD (Test-Driven Development) in the AI era. Letting the agent read console logs, fix its bugs, and iterate until green.
*   **Hands-on Task**: Write a failing test, start the agent, and instruct it to fix the file until the test passes.
*   **CTA (Main Funnel)**: "Ready to scale this to a team? Unlock the full 7-module [AI-Native SDLC Course](file:///Users/maxtomasello/git/own/software-engineering/courses/ai-native-sdlc/curriculum.md) and pre-order the book *'The Autonomous Engineer'* at a 40% discount."
