# Course Curriculum: The AI-Native SDLC

## Course Title
**The AI-Native SDLC: Building Software in the Era of Agentic AI**

## Description
This course explores the paradigm shift from traditional, human-bound software development lifecycles to an AI-assisted and AI-native SDLC. Developers will learn how to transition from syntax typing to agent orchestration, prompt/spec designing, rigorous automated validation, and self-healing systems. 

---

## 🎯 Course Overview & Objectives
By the end of this course, students will be able to:
1.  **Deconstruct** the traditional SDLC and identify bottlenecks that AI agents solve.
2.  **Orchestrate** modern agentic developers (e.g., Cursor, Windsurf, agent SDKs) for multi-file codebase updates.
3.  **Author** clear markdown specifications and blueprints that AI agents can execute with high reliability.
4.  **Architect** codebases designed to be read, modified, and validated by AI systems.
5.  **Build** a robust "safety net" using compilers and self-healing test pipelines to guide agentic code generation.
6.  **Manage** and operate multi-agent systems where humans take on the role of system architect and code reviewer.
7.  **Scale** AI-native dev patterns to enterprise teams under strict security and code ownership constraints.

---

## 👥 Target Audience
*   **Software Engineers** looking to supercharge their productivity and adapt to the rapid emergence of agentic tools.
*   **Tech Leads & Architects** designing workflows, developer tooling pipelines, and architectural standards for AI-assisted teams.
*   **Engineering Managers & Directors** seeking to structure teams and measure output in the era of exponential engineering velocity.
