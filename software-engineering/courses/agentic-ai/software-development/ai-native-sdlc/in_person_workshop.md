# 2-Day In-Person Workshop Guide: Migrating to an AI-Native SDLC

*   **Format**: Intensive 2-Day Bootcamp (16 Hours total).
*   **Target Audience**: Software Engineers, Tech Leads, Architects, and Engineering Managers.
*   **Capacity**: 15–30 attendees (divided into small breakout teams of 3–5).

This guide provides the schedule, instructor prompts, and breakout challenges for delivering an in-person, hands-on workshop.

---

## 📅 Day 1 Schedule: Foundations & The Spec-First Paradigm

### 🕒 09:00 - 10:30 | Session 1: The Transition from Syntax to Intent
*   **Lecture Focus**:
    - The history of SDLC models (Waterfall, Agile Scrum) and their inherent bottlenecks.
    - Reallocating cognitive load: Moving from boilerplate syntax generation to specification design.
*   **Live Demo**: Show how long it takes to manually write a user registration service vs. directing an agent to write it, focusing on review time.

### 🕒 10:45 - 12:30 | Session 2: Codebase Ergonomics & Indexing
*   **Lecture Focus**:
    - Designing repositories to be "AI-readable" (strict typing, file splitting, self-documenting JSDoc).
    - Under the hood of IDEs: How vector embeddings and semantic search feed context to LLMs.
*   **Practical Lab**: Students modify a dynamically-typed repository and observe how type definitions immediately reduce AI errors.

### 🕒 13:30 - 15:30 | Session 3: Breakout Challenge 1 – The Spec Swap
*   **Format**: Group Activity.
*   **Goal**: Prove the power of Spec-Driven Development.
*   **Instructions**:
    1.  Divide attendees into teams.
    2.  **Team A** writes a Markdown Specification for Feature X (e.g., a multi-tier tax calculator).
    3.  **Team B** writes a Specification for Feature Y (e.g., a session-token cache).
    4.  Teams swap specifications.
    5.  Using their respective IDE agents, teams implement the swapped specifications *without* asking the original writers for help.
*   **Review**: Discuss if the spec was complete enough for the agent to execute, or if it had to guess.

### 🕒 15:45 - 17:00 | Session 4: Code Review & Diff Auditing
*   **Lecture Focus**:
    - How to review a massive 10-file diff generated by AI.
    - Spotting AI hallucinated packages, performance bottlenecks, and security flaws.
*   **Live Challenge**: Spot the hidden SQL injection or logic bug in an AI-generated diff projected on the screen.

---

## 📅 Day 2 Schedule: Self-Healing & Scaling Teams

### 🕒 09:00 - 10:30 | Session 5: The Test Safety Net & Healing loops
*   **Lecture Focus**:
    - Why testing is critical to avoid regression loops in AI generation.
    - Setting up a compiler feedback loop in your local editor.
*   **Live Demo**: Run a Jest/Pytest loop and watch the agent intercept errors to fix its code in real-time.

### 🕒 10:45 - 12:30 | Session 6: Breakout Challenge 2 – The Red-Green-Agent Loop
*   **Format**: Coding Competition.
*   **Goal**: Create a feature using 100% test-driven development (TDD) via agents.
*   **Instructions**:
    1.  Instructor provides a repository with 10 failing integration tests.
    2.  Teams must configure a local watcher script that runs the tests and pipes outputs to a file.
    3.  Teams guide their agents to read this log and write code to make the tests pass.
    4.  The first team with all 10 tests green wins the challenge.

### 🕒 13:30 - 15:00 | Session 7: AI in the Enterprise – Managing Multi-Agent Workflows
*   **Lecture Focus**:
    - How personal coding setups differ from real-world team codebases.
    - Branch management strategies when multiple developers use agents (resolving merge conflicts).
    - Checking `.cursorrules` or `.windsurfrules` into git to standardize team rules.
    - Security guardrails: Preventing agents from executing random curl scripts or leaking API secrets.

### 🕒 15:15 - 17:00 | Session 8: Human-in-the-Loop Governance & Course Wrap-up
*   **Lecture Focus**:
    - The future engineering ladder: Staff Engineer as System Architect and Agent Manager.
    - Round-table discussion: How will attendees implement these tools at their respective companies next Monday?
