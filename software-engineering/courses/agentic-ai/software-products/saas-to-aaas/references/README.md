## 🔖 Key References

### 1. From RAG to Memory Systems: Building Stateful AI Architecture
*   **Source**: Oracle Developers Blog
*   **Original URL**: [Oracle Blog Link](https://blogs.oracle.com/developers/from-rag-to-memory-systems-building-stateful-ai-architecture?source=:so:ch:or:awr::::)
*   **Key Themes**:
    - **Beyond Static RAG**: Traditional Retrieval-Augmented Generation (RAG) is stateless—it retrieves static data per query. True agentic applications need *memory systems* that dynamically record new information, update user state, and write back to the database.
    - **Stateful AI Architecture**: How to design databases and application layers where the AI reads context from the database and writes updated facts/preferences back to a user profile schema.
    - **Memory Tiers**: Organizing memory into semantic vector memory (unstructured user interaction history) and relational memory (structured database tables tracking specific attributes).
